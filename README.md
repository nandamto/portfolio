# Portfólio Fernanda Monteiro

Site de uma página só (`index.html`), em português com versão em inglês. Não precisa instalar nada.

## Como publicar no GitHub Pages

1. No GitHub, crie um repositório público, por exemplo `portfolio`.
2. Envie o `index.html` e este `README.md` para a raiz do repositório (botão **Add file → Upload files**).
3. Vá em **Settings → Pages**, escolha **Deploy from a branch**, branch `main` e pasta `/ (root)`, e salve.
4. Em cerca de um minuto o site fica em `https://nandamto.github.io/portfolio/`.

## Como editar

Abra o `index.html` e procure por `var P=[`. Cada projeto é um bloco com título, texto em português e inglês (`t`, `l`, `d`), categorias (`chips`) e links (`links`). Para trocar um link, mude o último item de `links`.

## Antes de divulgar

- Os botões dos dois design systems (Letícia English Classes e o seu manual de marca) apontam para artifacts do claude.ai. Compartilhe cada um pelo claude.ai, senão quem visitar vai ver erro.
- Os Reels, carrosséis, a De Além Mar e os kits de imprensa ainda não têm link nem arquivo. Quando tiver, coloque em `links` de cada projeto.
