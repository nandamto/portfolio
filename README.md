# Portfólio Fernanda Monteiro

Site estático, sem instalação. Duas versões:

- `index.html`: português (abre em inglês para quem tem o navegador em inglês)
- `assets/`: imagens e vídeo que aparecem dentro dos projetos (pizza, Tarot da Nata, De Além Mar, Bolos da Mónica, Ketel One e Marreco)
- `en/index.html`: inglês fixo. Use este link para vagas e clientes de fora: `https://nandamto.github.io/portfolio/en/`

Também funciona `https://nandamto.github.io/portfolio/#en` para abrir qualquer versão em inglês.

## Como publicar no GitHub Pages

1. No repositório `portfolio`, envie **a pasta inteira** (o `index.html`, as pastas `en` e `assets` e o `README.md`) em **Add file → Upload files**. Descompacte o zip antes e arraste os itens, mantendo as pastas `en` e `assets`.
2. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main` e pasta `/ (root)`.
3. O site fica em `nandamto.github.io/portfolio`.

## Como editar

Abra o `index.html` e procure por `var P=[` (projetos), `var CS={` (desafio, o que fiz e resultado) e `links:[` (botões). Se mudar o texto, faça a mesma mudança em `en/index.html`.
